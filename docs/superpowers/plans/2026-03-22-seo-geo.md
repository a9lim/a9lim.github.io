# SEO & GEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add comprehensive SEO and GEO (Generative Engine Optimization) markup to the root site and all four simulation subprojects so search engines and AI systems can discover, index, and cite the content effectively.

**Architecture:** Static HTML-only approach — all meta tags, JSON-LD, canonical links added directly to each `index.html`. A `robots.txt` and `sitemap.xml` at the root complete crawl infrastructure. Descriptions emphasize educational value while remaining approachable.

**Tech Stack:** HTML meta tags, JSON-LD (schema.org), XML sitemap
