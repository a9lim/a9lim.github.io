The shared language

The thread between the four should be the paper, and the inks should be free. That keeps them recognizably a9l.im while letting each one look like nothing else on the web.

Shared by all four

  • The ground. The site's neutral canvas in both themes. No sim gets its own background color.
  • Newsreader for every word, in the chrome and on the canvas.
  • The colophon. Seal and name at the top left, same size and place in every sim. It replaces the toolbar strip.
  • A live figure caption under the scene, in italic, saying what you are looking at with its current values. It replaces the hint pill.
  • Hairline structure in the controls: no cards, shadows or rounded panels.
  • One set of inks for data, named for pigments and paired per theme.
  • One red per sim, spent on the thing you would point at.
  • The keyboard grammar and the about panel.

Owned by each

  • The medium: a spacetime you can tilt, a molecular painting over a transit map, an atlas, a newspaper.
  • Its choice of inks from the shared set below, and what the red means there.
  • The renderer: WebGPU where the scene needs it, Canvas or plain DOM where it doesn't.
  • The control layout, shaped to the medium instead of one sidebar for all.
  • A signature view that only that subject could have.

Depict, don't decorate

The site's ban on glow, grain, shimmer and flourish stays in force for chrome. Inside a scene, an effect ships only if it reads a quantity in the model: density is concentration, line weight is flux, bead spacing is proper time. If we can't name the quantity, the effect doesn't ship.

Open on a living frame

No splash screen and no empty state. Each sim boots into its best preset, already running, so the first frame shows what the sim is for.

Pattern before hue

Where a scene encodes state, pair color with a pattern: stipple, hatching, dash, bead. The scene then survives grayscale, print and color-vision differences, and gains texture that means something.

The extended palette, as inks

Today's extended palette is thirteen hues at one lightness and full chroma, shared by both themes. Next to Newsreader on near-white paper they read as screen colors, and slate is a warm gray that sits off the site's neutral axis. The proposal is eleven inks named for pigments, each with its own light and dark value. Every ink clears 4.5:1 on the canvas and on panels in both themes, so any of them can set a label as well as mark data. Red leaves the set, because oxblood is the one red. Slate's jobs go to graphite, the site's own muted neutral.
